A project to seamlessly extract text from images as if they weren't images at all. Written in C++, this project uses Google's Tesseract library behind the scenes to ensure greater accuracy than other character recognition solutions.

This was my first desktop app to have a full graphical user interface built with GTK, and it's cross platform with support for Mac, Windows, and Linux.
