## Running Locally


```sh-session
git clone https://github.com/alexanderkonchar-personal/portfolio.git
cd portfolio
```


Create a `.env` file similar to [`.env.example`](https://github.com/alexanderkonchar-personal/portfolio/blob/main/.env.example).

Then install dependencies and run the development server:
```sh-session
pnpm install
pnpm dev
```
